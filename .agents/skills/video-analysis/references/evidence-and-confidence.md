# Evidence, status, and confidence

Three independent tags describe any significant claim. Keep them separate; the earlier single E1-E11 list mixed source types with epistemic status.

## Source (where the evidence comes from)

| Tag | Meaning | Example |
|---|---|---|
| visual | Something visibly present | A person raises their right hand at 00:03 |
| audio | Something audibly present | A loud percussive sound at 00:04 |
| text | Readable on-screen text or captions | "WARNING" in red, centered |
| temporal | Timing relationship between events | The audio spike occurs just before the image change |
| metadata | Container or file information | File reports a duration of 1:58 |
| user | Context supplied by the user | The user says it is an artistic collaboration |

Motion patterns and repeated structures are visual or temporal evidence; tag them as such.

`user` evidence is context, never observation. If the media contradicts it, report the contradiction.

## Status (what kind of claim it is)

- **observed:** directly seen, heard, or read.
- **inferred:** drawn from observed evidence. State the evidence.
- **hypothesis:** a testable interpretive proposal. State what would confirm or refute it.
- **unknown:** cannot be determined from the available media.

## Confidence

- **confirmed:** directly observable and reliable.
- **probable:** strongly supported but not absolute.
- **possible:** consistent with the evidence, not sufficiently supported.
- **uncertain:** evidence is ambiguous or insufficient.

Observed claims are assumed confirmed unless flagged (for example "partially occluded", "text partly legible"). Apply confidence mainly to inferences and hypotheses.

**Contradicted** is not a confidence level. Use it when two pieces of evidence conflict, for example: "The user description says there is no speech, but speech is audible at 00:20."

Confidence guide:

- *High:* clear, repeated across channels, legible, unambiguous action.
- *Medium:* partial visibility, brief event, noisy audio, ambiguous gesture, indirect cues.
- *Low:* heavy blur, occlusion, very short duration, contradictory signals, implied rather than shown action, motive or emotion without support.

When uncertain, give the best-supported reading plus alternatives.

## Hedging language

Preferred: "appears to", "may suggest", "one possible reading is", "consistent with", "cannot be confirmed from the media alone".
Avoid: "clearly intends", "obviously", "is trying to", "the creator wants".

## Description, analysis, judgment

Keep three layers distinct.

- *Description:* "The clip contains three image changes within two seconds."
- *Analysis:* "The rapid changes create a segmented viewing rhythm."
- *Judgment (label as evaluation):* "The pacing may feel abrupt to some viewers."

Prefer concrete wording over loaded adjectives. Instead of "creepy", write: "close-up of a face, low light, sustained stillness, high-pitched tone."

## Candidate interpretation template

> Candidate interpretation: [statement]
> Supporting evidence: [segments / items]
> Opposing evidence: [segments / items]
> Alternative explanations: [list]
> Confidence: [level]
